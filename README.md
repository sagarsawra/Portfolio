# Sagar Sawra — Portfolio

Personal portfolio website built with React and Vite.

## Tech Stack

- React 19
- Vite
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
